# Как пользоваться pen-motion

**Что умеет.** Берёт экраны из макета pen.dev и собирает живой макет на React и Motion. Стиль движения задаётся на весь продукт, как цветовая тема: кнопки, поля, карточки, появление экранов. Claude подбирает 2–3 стиля-кандидата по референсам, вы переключаете их на лету и выбираете один.

**Ограничения.** В живом макете работают только киты с адаптером, сейчас это только **shadcn** (кит `design/libraries/shadcn-obra`). Для другого кита Claude сначала предложит сделать адаптер. Только веб.

## Что сказать Claude

- «оживи макет design/<продукт>.pen»
- «подбери стиль движения для лендинга»
- «сними движение с https://… и сделай стиль по нему»
- «какие анимации подойдут для OTP»
- «добавь экран Settings в выбранном стиле»
- «собери сдачу»

## Как идёт работа

1. Макет продукта лежит прямо в `design/` (`design/<продукт>.pen`), из подпапки он не видит киты.
2. Claude ищет референсы в Screenrove и снимает движение с 2–4 живых сайтов (`capture-motion`). Анимации не выдумываются: каждый кандидат повторяет движение своего референса.
3. Кандидаты сильно отличаются идеями, а не числами одной анимации. У каждого свой заметный фирменный приём.
4. Стиль выбирается **один раз** на 1–2 ключевых экранах. Остальные экраны сразу собираются в нём, без новых кандидатов. Варианты отдельного места (например OTP) Claude делает только по вашей просьбе.

## Где Claude ждёт вас

- **Подключить кит в pen.dev**: Libraries → «+» у Imported Libraries → `design/libraries/shadcn-obra/shadcn-obra.lib.pen`. Агент этого сделать не может.
- **Выбрать стиль**: открыть ссылку на `npm run dev`, переключить кандидатов на панели и сказать, какой берёте.
- Выбрать вариант места — только если вы сами просили варианты.

## Что получается

- Живой макет `<продукт>/mockup/`: `npm run dev` из этой папки.
- Один HTML-файл `<продукт>/mockup/dist/index.html`, открывается двойным кликом.
- Спецификация для разработки `<продукт>/docs/motion-spec.md`: токены, роли, параметры, источники и лицензии.
- Снятые референсы `design/motion/captures/<сайт>/record.md`.

Готовый пример — продукт `nimbra-demo/` (макет `design/nimbra-demo.pen`, стиль `kinetic`).
