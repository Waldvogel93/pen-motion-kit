Пример формата. Три стиля здесь — не стартовый набор

Так выбирать анимации удобно?

Пример для одного места — ввод OTP. Три варианта разного характера идут по кругу: ввод → ошибка → верный код → успех. Нажми на карточку, чтобы отметить понравившийся.

Код из SMS

A · Сдержанный

В духе Linear и Stripe. Цифры мягко проявляются, рамка скользит к следующей ячейке, ошибка — короткая лёгкая тряска.

  • появление 180 мс, ease-out
  • рамка 220 мс
  • тряска ±6 px, 360 мс
Motion: layoutId + fade
Код из SMS

B · Пружинный

В духе Apple и финтеха. Цифры выпрыгивают с отскоком, проверка идёт волной, при успехе ячейки схлопываются в галочку.

  • пружина с перелётом ~15%
  • волна: 70 мс между ячейками
  • тряска ±12 px, 450 мс
Motion: spring + stagger
Код из SMS

C · Эффектный

Для лендингов и AI-продуктов. Луч бежит вокруг активной ячейки, цифры проявляются из размытия, проверка — блик, успех — конфетти.

  • луч: оборот за 1,6 с
  • размытие 8 px → 0, 350 мс
  • конфетти: 26 частиц
Magic UI: Border Beam, Blur Fade, Confetti

Это набросок на чистом JS, он только показывает формат. В настоящем процессе такой выбор будет для каждого места на экране, которое стоит оживить. Под каждым вариантом — откуда он взят (библиотека и компонент) и точные параметры. Выбранный вариант записывается в спецификацию движения и попадает в HTML-макет.
