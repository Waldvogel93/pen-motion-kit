# Хороший — растворение

## Характер
Спокойное появление каскадом, короткий отклик на нажатие.

## Когда подходит
Деловые экраны, где движение не должно отвлекать.

## Референсы
- [Правила движения Screenrove](https://screenrove.com) — пример для теста.

## Изменения вида в покое
Нет

## Источники и установка
Только пакет `motion`: `npm install motion`.

## Reduced motion
Появление мгновенное, у кнопки только растворение без масштаба.
