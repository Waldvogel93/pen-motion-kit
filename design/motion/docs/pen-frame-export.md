# Картинка рамки из pen.dev

Как получить PNG экрана из `.pen`, чтобы сверить с ним живой макет (`npm run compare`). Проверено 31.10.2026 на расширении pen.dev для VS Code.

## Рабочий способ: `Export` в Pencil MCP

Человек не нужен. В `execute` есть операция `Export(nodeIds, format, outputPath, options)`.

1. Открыть макет во вкладке: `code -r "design/<продукт>.pen"`. С неоткрытым файлом `execute` молча работает с активной вкладкой.
2. Вызвать `mcp__pencil__execute` с `filePath` этого файла:

```js
const s=Get((n,c)=>{c.skipChildren();return n.type==="frame"&&!n.id.includes(":")&&!n.name.startsWith("_")?[n.id,n.name]:undefined})
Export(s.map(x=>x[0]),"png","<корень>/<продукт>/mockup/compare/pen/_raw",{scale:1})
for(const [i,nm] of s)Print("MAP",i,nm)
```

   - Берутся только рамки верхнего уровня: обход всего документа падает на файлах с экземплярами из библиотек, поэтому `skipChildren`.
   - Рамки подключённых библиотек отсеиваются по `:` в id (`H:…`), черновики — по `_` в начале имени.
   - Каждая рамка пишется в папку как `<id>.png`, в ответе строки `Exported /d:/…/<id>.png` и `MAP <id> <имя>`.
   - Чтобы выгрузить один экран, передать в `Export` только его id.
3. Переименовать по строкам `MAP`: `_raw/<id>.png` → `compare/pen/<Экран>.png`. В имени состояния `/` заменить на `--`: `Login / error` → `Login--error.png`. Папку `_raw` удалить.

**Проверено:** рамка 1280×800 дала PNG 1280×800.

**Ловушки:**
- Масштаб по умолчанию 2. Для сверки всегда `{scale:1}`, иначе размер окна в `compare` будет вдвое больше рамки.
- Путь — абсолютный. В ответе он печатается как `/d:/…`, файл при этом лежит в `D:/…`.
- Существующий файл с тем же id перезаписывается.
- Рамка без заливки выгружается с прозрачным фоном, и `compare` считает прозрачное белым. Если фон экрана не белый, задать рамке заливку фона до выгрузки.
- Папка `compare/` в git не попадает (`.gitignore` макета).

## HTML из рамки

`Export([id], "html-tailwind", "<путь>.html")` (или `"html-css"`) выгружает рамку в HTML без участия человека. Это та же выгрузка, что в панели Code. Внутри Tailwind и шрифты Google подключаются по сети, картинки — относительными путями. Годится как справка по раскладке, например для кита без React-кода (SnowUI). В живой макет как есть не идёт.

## Что ещё проверено и не нужно

- CLI `@pen.dev/cli`: по документации `pen --in <файл>.pen --export <файл>.png` выгружает картинку результата целиком и требует `pen login`. Отдельную рамку по имени так не выбрать. Не проверялся: способ через MCP проще.
- `browser` в Desktop Pen (`mcp__pencil-desktop__browser`) для выгрузки не нужен.

## Запасной ручной способ

Если MCP недоступен: выделить рамку → Export → PNG, масштаб 1x → сохранить в `<продукт>/mockup/compare/pen/<Экран>.png`.
