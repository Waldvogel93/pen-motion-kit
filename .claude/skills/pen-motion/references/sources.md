# Источники анимаций и как их ставить

Проверено **31.10.2026**:
- живые страницы — CLI `npx defuddle parse <url> --md` (без глобальной установки);
- реестры — командами `npx shadcn view …` и `npx shadcn search …` в шаблоне. Они только читают, файлы не меняют.

Команды и лицензии со временем меняются. Перед тем как ставить новый приём, проверь страницу заново тем же `defuddle`.

## Общие правила

- **Что брать.** Из библиотек берутся приёмы, параметры и декоративные слои поверх компонентов кита: бегущий луч, подсветка за курсором, конфетти, счётчики, эффекты текста, фон. Компоненты кита библиотечными не заменяются. Библиотечный компонент целиком ставится, только если в ките нет аналога, и перекрашивается токенами кита.
- **Где ставить.** Команды запускаются из `<продукт>/mockup`, там уже есть `components.json`. `npx shadcn …` берёт версию CLI из макета, `npx shadcn@latest …` — последнюю.
- **Сначала посмотреть.** `npx shadcn view <элемент>` печатает зависимости и код элемента реестра, ничего не меняя. `npx shadcn search @<реестр>` перечисляет элементы реестра.
- **Следить за зависимостями.** Некоторые элементы тянут другую библиотеку анимации, например GSAP. Вторая система движения спорит с ролями и приносит свою лицензию. Брать элементы на Motion или переписывать приём на Motion.
- **`cn` в макете.** `src/lib/utils.ts` реэкспортирует `cn` из пакета `cn`, а не собирает его из `clsx` + `tailwind-merge`. Если компонент библиотеки ждёт `cn` из `@/lib/utils`, импорт сработает. Слияние конфликтующих классов стоит проверить глазами.
- **Записать.** Каждый взятый приём — в паспорт стиля: строка роли («Источник», «Лицензия») и команда в «Источниках и установке».

## Motion

- Страница: https://motion.dev/docs/react-installation
- Установка: `npm install motion`, импорт из `"motion/react"`. Нужен React 18.2 или новее. Для Vite настройка не нужна.
- В шаблоне уже стоит (`motion` ^14.9.0), ставить ничего не надо.
- Лицензия: MIT, «Copyright (c) 2024 Motion B.V.» — https://github.com/motiondivision/motion/blob/main/LICENSE.md
- Свежую документацию API смотреть через Context7 MCP (`/websites/motion_dev`).

## Animate UI

- Страницы: https://animate-ui.com/docs, https://animate-ui.com/docs/installation
- **Основной способ по документации**:
  - `npm install @animate-ui/react motion`;
  - CLI `npx @animate-ui/cli@latest animate all` или `animate <компонент> --dry-run`;
  - CLI находит компоненты shadcn через `components.json`, меняет импорт их примитивов (`radix-ui` → `@animate-ui/react/primitives/radix-ui`) и удаляет CSS-классы анимаций;
  - темп задаёт `AnimateUIProvider` (`tempo`, `checkAnimation`).
- **В живом макете `animate all` не запускать.** CLI переписывает компоненты кита сразу для всех стилей. Движение уходит из ролей, и переключатель стилей перестаёт им управлять. Из Animate UI берутся приёмы и параметры для ролей.
- **Реестр shadcn `@animate-ui`** тоже работает: `npx shadcn search @animate-ui` вернул 789 элементов (`@animate-ui/backgrounds-stars`, `@animate-ui/buttons-flip`, …). Установка: `npx shadcn@latest add @animate-ui/<элемент>`. Годится для декоративных слоёв и фона.
- Лицензия: «MIT + Commons Clause License Condition», Copyright (c) 2025 Elliot Sutton — https://github.com/imskyleen/animate-ui/blob/main/LICENSE.md. Использовать в приложении, на сайте или в продукте можно, в том числе коммерчески. Продавать или распространять сами компоненты нельзя.

## Magic UI

- Страница: https://magicui.design/docs/installation. Установка «ровно как у shadcn/ui». На странице `pnpm dlx shadcn@latest add @magicui/globe`, для npm это `npx shadcn@latest add @magicui/<компонент>`.
- Пример: Border Beam (https://magicui.design/docs/components/border-beam) → `npx shadcn@latest add @magicui/border-beam`. По `npx shadcn view @magicui/border-beam` он зависит только от `motion`.
- Не все компоненты так просты. На 31.10.2026 `@magicui/magic-card` зависит от `next-themes` (`npx shadcn view @magicui/magic-card`), а второй провайдер темы ради декоративного слоя не ставят. Border Beam двигает `offset-distance` из JS на каждом кадре: проверяй стоимость слоя.
- Лицензия: MIT, «Copyright (c) Magic UI» — https://github.com/magicuidesign/magicui/blob/main/LICENSE.md

## React Bits

- Страница: https://reactbits.dev/get-started/installation
- Установка: `npx shadcn@latest add @react-bits/SplitText-TS-TW`. Окончание выбирает вариант: JS или TS, потом CSS или TW. Для макета — `-TS-TW`. Можно и вручную, со вкладки Code на странице компонента.
- **Зависимости смотреть до установки.** `SplitText-TS-TW` тянет `gsap@^3.13.0` и `@gsap/react@^2.1.2` (`npx shadcn view @react-bits/SplitText-TS-TW`). Это вторая система движения, а лицензию GSAP здесь не проверяли. Без проверки не брать, лучше переписать приём на Motion.
- Лицензия: «MIT + Commons Clause License Condition v1.0», Copyright (c) 2026 David Haz — https://github.com/DavidHDev/react-bits/blob/main/LICENSE.md. Использовать в приложении можно, в том числе коммерчески. Продавать, сублицензировать и распространять сами компоненты нельзя: ни по отдельности, ни набором, ни в переносе на другой стек.

## Снятые референсы

`node design/motion/scripts/capture-motion.mjs <url>` (из корня репозитория) открывает публичную страницу в браузере, записывает движение и пишет `design/motion/captures/<slug>/record.md`. Когда и как снимать, как читать запись — [styles.md](styles.md), шаг 2.

- **Что снимается.** CSS-переходы и анимации, Web Animations API, замеры по кадрам: появление при загрузке, прокрутка, наведение, фокус. Кривые и пружины, задержки, каскады, черновик токенов.
- **Что не снимается** (раздел `## Ограничения` в `record.md`): canvas и WebGL, в том числе Lottie на canvas; видео; морфинг SVG-путей; CSS-переменные, которые меняются из JS на предке; анимации на scroll-timeline. Это видно только на кадрах и видео в `media/`, воспроизводится «на глаз», основа «видео». Движение по клику (вкладки, аккордеоны, модальные окна) не снимается совсем: съёмка не кликает.
- **Привязка к прокрутке.** Параллакс и scrub на JS записываются строкой «привязано к прокрутке: N px за M px прокрутки» — без длительности и кривой, в токены не входят; повторять привязкой к прокрутке с тем же отношением N / M.
- **Основа чисел.** `точно (CSS)` и `точно (WAAPI)` — из кода страницы; `замер` — приблизительно, по кадрам.
- **Образец, не код.** Код, тексты и картинки сайта не копируются. В паспорт — «снято с <домен>» и «своя реализация (образец: <домен>)».
- **Только публичное.** Без входа в аккаунт, без кликов, меняющих данные. Экраны Screenrove со `scope: "signed-in"` не снимаются.
- Медиа (`media/frames`, `media/video.webm`) в git не попадает.

### Ключевые числа `get_motion_guidelines` (31.10.2026)

Это **снимок на дату**, правила по умолчанию. Обычно хватает его. `mcp__screenrove__get_motion_guidelines` вызывать, если стиль отступает от правил или числа нужно перепроверить. Собственная спецификация записи важнее этих значений. Отступление записывается в паспорт стиля.

- **Зачем.** Анимировать, только когда движение объясняет: причину и следствие, откуда что взялось, ответ на действие, редкий осознанный восторг. То, чем пользуются весь день, не анимировать. Действия с клавиатуры не анимировать никогда.
- **Длительности.**
  - Интерфейс — до 300 мс.
  - Нажатие — 100–160 мс, подсказка — около 125 мс, меню и поповеры — 150–200 мс (выпадающий список — 180 мс), модальные окна и шторки — 200–300 мс.
  - Мелкий отклик (чекбокс, переключатель) — около 100 мс, крупные перемещения — 200–400 мс. С 500 мс анимация начинает тянуться.
- **Выход быстрее входа**: поповер появляется за 300 мс, уходит за 200–250 мс.
- **Кривые.**
  - Вход и выход — ease-out, никогда ease-in. Сильный ease-out — `cubic-bezier(0.23, 1, 0.32, 1)`.
  - Ease-in-out `cubic-bezier(0.77, 0, 0.175, 1)` — только для коротких перемещений в пределах экрана, не дольше 300–500 мс.
  - Шторки больше 500 мс — `cubic-bezier(0.32, 0.72, 0, 1)` (Vaul).
- **Масштаб.**
  - Не начинать с `scale(0)`: от 0.9 и выше (хорошо 0.93) вместе с opacity 0.
  - Кнопка при нажатии — `scale(0.97)`.
  - Поповеры масштабируются от своего триггера (`transform-origin`: `var(--radix-dropdown-menu-content-transform-origin)` в Radix).
- **Подсказки.** Первая — с задержкой, следующие — сразу и без анимации. Открытие — 125 мс ease-out от 0.97.
- **Что анимировать.** Только transform и opacity, никогда раскладку и никогда `transition: all`. Каждая анимация прерываема: для интерактивных состояний лучше переходы и пружины.
- **Жесты и направление.** Жест идёт за пальцем 1:1, решение — на отпускании. Уходить тем же путём, каким пришёл.
- **Каскад.** 30–50 мс на элемент, вся последовательность — до ~400 мс, только видимое. У motion-primitives 30 мс на символ, 50 на слово, 100 на строку.
- **Размытие.** Если перекрёстное растворение выглядит не так, добавить 2 px размытия.
- **Reduced motion.** Смысл остаётся, движение уходит: вместо сдвига и масштаба — растворение той же или меньшей длины или ничего. Само изменение состояния происходит всё равно.
- **Чем анимировать.** Сначала CSS, потом Web Animations API, потом JS-библиотеки. Стек макета — Motion (решение проекта), поэтому из правила следует держаться transform и opacity.

**Токены длительности (Material 3):**

| Токен | мс |
|---|---|
| short1 / short2 / short3 / short4 | 50 / 100 / 150 / 200 |
| medium1 / medium2 / medium3 / medium4 | 250 / 300 / 350 / 400 |
| long1 / long2 / long4 | 450 / 500 / 600 |
| extra-long1 | 700 — только фон и онбординг, не отклик |

**Пружины.** Material 3 задаёт коэффициент затухания, а Motion ждёт абсолютный `damping`. Перевод: `damping = ratio × 2 × √(stiffness × mass)`.

| Пружина | Значение | Для чего |
|---|---|---|
| M3 spatial fast | stiffness 1400, ratio 0.9 (~220 мс) | переключатели, чипы, ручки |
| M3 spatial default | stiffness 700, ratio 0.9 → damping ≈ 48 (~295 мс) | меню, карточки, панели. Это `spring.snappy` в `_template` |
| M3 spatial slow | stiffness 300, ratio 0.9 → damping ≈ 31 (~480 мс) | крупные перемещения. Это `spring.soft` в `_template` |
| M3 effects default | stiffness 1600, ratio 1 → damping 80 (~300 мс) | opacity и цвет, без перелёта |
| SwiftUI .smooth / .snappy / .bouncy | stiffness 157.9, damping 25.1 / 21.4 / 17.6 | спокойно / с намёком на жизнь / игриво, редко |
| Digit roll (motion-primitives) | stiffness 280, damping 18, mass 0.3 (~350 мс) | числа и посимвольные смены текста |

Готовые токены Material 3, Apple и Open Props годятся как отправная точка. Полный список кривых и пружин — в ответе `mcp__screenrove__get_motion_guidelines`.
